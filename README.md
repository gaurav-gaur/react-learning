# React Learning

Hands-on exercises and experiments while learning React from the official documentation.

## Objective

Learn React fundamentals, understand frontend development, and build small Single Page Applications through practical implementation.

## Tech Stack

- React
- JavaScript
- HTML and CSS
- Vite
- Node.js and npm

## Learning Resources

- [React Quick Start](https://react.dev/learn)
- [React Documentation](https://react.dev/)
- [Vite Documentation](https://vite.dev/guide/)

## Running Locally

```bash
cd quick-start
npm install
npm run dev
```

Open the local URL displayed in the terminal.

## Learning Approach

1. Read the official documentation.
2. Implement the examples locally.
3. Experiment with different implementations.
4. Commit completed exercises to GitHub.
5. Review and improve the code.
